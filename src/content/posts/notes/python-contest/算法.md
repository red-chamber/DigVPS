## 埃氏筛

```python
is_prime=[True]*(n+1)
is_prime[1]=is_prime[0]=False # 1 和 0 不是素数

for i in range(2,int(math.sqrt(n))+1): # 2 到根号 n
	if is_prime(i): # i 是素数
		for j in range(i*i,n+1,i): # 把后面的 i 的倍数全部标记为非素数，步长 i
			is_prime[j]=False
```
时间复杂度 $O(nloglogn)$
