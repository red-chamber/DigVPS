## Neovim

| 操作                | 按键/命令                           |
| ----------------- | ------------------------------- |
| 保存                | `:w`                            |
| 退出                | `:q`                            |
| 保存并退出             | `:wq`                           |
| 强制退出、不保存          | `:q!`                           |
| **撤销** / 重做       | `u` / `Ctrl + r`（不是 `Ctrl + z`） |
| 复制当前行             | `yy`                            |
| 删除/剪切当前行          | `dd`                            |
| 粘贴到光标后 / 前        | `p` / `P`                       |
| 查找关键词；下一个 / 上一个结果 | `/关键词` 后回车；`n` / `N`            |
| 跳到指定行             | `:行号`，如 `:20`                   |
| 跳到文件开头 / 结尾       | `gg` / `G`                      |
| 运行终端命令            | `:!命令`，如 `:!python3 main.py`    |
| 跳到本行最开头（含缩进）      | `0`                             |
| 跳到本行第一个非空字符       | `^`                             |
| 跳到本行末尾            | `$`                             |
| 向后跳一个单词开头         | `w`                             |
| 向前跳一个单词开头         | `b`                             |
| 跳到当前/下一个单词结尾      | `e`                             |
| 选中字符后移动选择范围       | `v`，再用方向键或 `w`、`e`、`$`          |
| 选中整行              | `V`                             |
| 矩形块选中             | `Ctrl + v`                      |
| 全选                | `ggVG`                          |
| 复制选中内容            | `y`                             |
| 剪切选中内容            | `d`                             |
