先看一个有问题的 parallel 块：
```c
global_result = 0.0;
# pragma omp parallel num_threads(thread_count)
{
	# pragma omp critical
	global_result += Local_trap(double a, double b, int n);
}
```
这个程序的计算过程实际上是完全串行的，可以声明一个私有变量来解决这个问题：
```c
global_result = 0.0;

#pragma omp parallel num_threads(thread_count)
{
    double my_result = Local_trap(a, b, n);  // 每个线程独立计算

    #pragma omp critical
    global_result += my_result;              // 只在合并时短暂加锁
}
```

`reduction` 子句是对 `每个线程算一个局部结果->把所有局部结果求和` 这种常见的模式的封装：
```c
global_result = 0.0;

#pragma omp parallel num_threads(thread_count) \
    reduction(+: global_result) // 意为 global_result 最终要用加法归并
global_result += Local_trap(a, b, n);
```
其中 `\` 是续行符

`reduction` 译为归约，即把很多个值反复用同一种运算合并为一个值。减法不适合归约，因为它不满足结合律。浮点数求和可能因为精度有极小的差异。
