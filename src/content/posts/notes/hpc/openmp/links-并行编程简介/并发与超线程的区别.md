一个是软件概念，一个是 CPU 硬件能力。

| 概念 | 并发 | 超线程 |
|---|---|---|
| 所在层面 | 软件/操作系统 | CPU 硬件 |
| 关注点 | 多个任务如何同时或交替推进 | 一个物理核心如何更充分地运行多条线程 |
| 是否必须多核 | 不必须，单核也能并发 | 不必须多核，但需要 CPU 支持 SMT/超线程 |
| 实现方式 | 多线程、协程、异步任务、事件循环等 | CPU 把一个物理核心暴露成多个逻辑核心 |
| 是否等于真正并行 | 不一定 | 不一定，取决于物理核心数与调度情况 |

超线程是一个物理核心允许两条硬件线程同时驻留和推进：
当 A 在等待某些 CPU 内部资源或内存数据时，核心可以更积极地推进 B。因此，超线程能帮助提高吞吐量，但 A 和 B 仍会共享该物理核心的大量资源。

三者关系可以记成：
```text
并发：任务组织方式
并行：多个计算单元在同一时刻真正执行
超线程：让一个物理核心更好地承载多条执行流的硬件技术
```

比如 4 核 8 线程的 CPU：
- 程序创建 100 个 `std::thread`：这是并发任务。
- 最多可有约 8 条软件线程被操作系统同时调度到 8 个逻辑核心：这是硬件支持下的并行推进。
- 但其中每一对逻辑核心共享一个物理核心：这是超线程，不等同于 8 个独立物理核。
