## 指令级并行与 CPU 流水线

经典的流水线模型，一条指令有以下步骤：
```text
指令取指- - Instruction Fetch(IF)
指令译码- - Instruction Decode(ID)
指令执行- - Instruction Execution(EX)
访存 - - Memory Access( MEM)
写回- - Write-Back(WB)
```

五级流水线，多条指令同时在 CPU 各部件执行

## 分布式并行（MPI）

MPI：Message Passing Interface

- 每个计算机都运行自己的操作系统，而不是运行共同的、全系统范围的操作系统或其一部分
- 进程的概念：每个进程空间的指令和数据都是相互独立的
- 多个进程分布在多个计算机上面共同完成同一个计算任务
- 进程间通过消息传递机制传递计算数据、同一计算步调，如 MPI

## 共享存储式并行（OpenMP、OpenCL、OpenACC）

初始问题（在一个进程空间内）--> 基于算法的任务划分（共享原理的（进程）存储空间）

- 线程的概念，和进程的区分？ [答案](/posts/notes/hpc/openmp/links-并行编程简介/线程和进程的区分/)
- 线程之间不谈及消息传递，在主存**同一个进程空间**内**共享数据**
- 线程之间存在控制机制（异步、同步、原子……）
- 什么是超线程？ [答案](/posts/notes/hpc/openmp/links-并行编程简介/超线程/)

## 超算平台的体系结构

一个节点 64 个核心，每一个核心的行为，称为**核内行为**（指令级并行、SIMD（数据并行））。**节点内跨核行为**属于跨核并行，是共享存储式并行，也称片上通讯。既跨节点也跨核的，称为**跨节点跨核行为**，也属于跨核并行，是分布式并行，也称网络通讯。

通常超算平台同时采用以上三种行为，即混合并行。

一个服务器有多个计算节点，它们计算的延迟不一样，采用 NUMA 架构（[什么是 NUMA 架构?](/posts/notes/hpc/openmp/links-并行编程简介/numa架构/)）

## 并行与并发

并发：多个任务逻辑上同时执行、在同一个时间段内，两个或多个程序执行，有时间上的重叠（宏观上是同时，微观上仍是顺序执行） 
[并发与超线程的区别](/posts/notes/hpc/openmp/links-并行编程简介/并发与超线程的区别/)
并行：多个任务严格同时执行
并行比并发更能充分利用系统的计算硬件资源，并发有 CPU 核心的空转
各种各样的程序或问题，能够实现并发的更多也较为容易，能够严格并行的较少，但是却很关键。

## 异构并行

对于超算平台来说，计算部件可以是多样化的，除了 CPU 还有：GPU、MIC（Intel 集成众核）、主从核（神威）、Matrix2000（天河 2A）等，一般统称为加速器（或加速核）。
CPU 和加速器在体系结构上是不一样的，CPU 协同加速器共同完成计算任务，称为异构（并行）。加速器端也通常是线程级并行，有的加速器也支持跨部件进程间通讯，比如 GPU。

## 分布式和共享存储式并行

混合并行模型：用分布式并行（MPI）做进程间通信，用 OpenMP 做进程内部的多线程并行。

通常情况下
- 同一个 OpenMP 进程里的线程共享地址空间；
- 不同 MPI 进程通常各有独立地址空间，不能直接读写彼此的普通变量；
- MPI 进程间要靠消息传递交换数据。

即，OpenMP 负责“共享内存中的线程协作”，MPI 负责“不同进程（可能跨机器）的通信”。
