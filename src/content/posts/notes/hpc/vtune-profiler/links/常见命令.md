常用格式是：

```powershell
vtune -collect <分析类型> -r <结果目录> -- <程序> <程序参数>

g++ -O2 -g -fno-omit-frame-pointer -std=c++17 VTunePractice.cpp -o VTunePractice.exe
```

常用命令如下。

```powershell
# 查看版本
vtune --version

# 查看完整帮助
vtune -help

# 查看某项采集或报告的参数
vtune -help collect
vtune -help report
vtune -help collect hotspots

# 打开图形界面
vtune-gui

# 打开某个结果
vtune-gui .\result-hotspots
```

常见分析类型：

```powershell
# CPU 热点：最推荐的起点，找耗时函数/源码行
vtune -collect hotspots -r .\result-hotspots -- .\app.exe

# 并行与线程问题：找线程空闲、同步等待、负载不均
vtune -collect threading -r .\result-threading -- .\app.exe

# 内存访问：查缓存未命中、内存带宽等
vtune -collect memory-access -r .\result-memory -- .\app.exe

# HPC 程序性能：适用于计算密集型、MPI/OpenMP 等
vtune -collect hpc-performance -r .\result-hpc -- .\app.exe

# 微架构探索：深入查前端、后端、分支、缓存等 CPU 瓶颈
vtune -collect uarch-exploration -r .\result-uarch -- .\app.exe

# GPU 计算/媒体热点：适合 SYCL、Intel GPU 内核分析
vtune -collect gpu-hotspots -r .\result-gpu -- .\app.exe

# CPU-GPU 卸载分析：适合 OpenMP target/offload
vtune -collect gpu-offload -r .\result-offload -- .\app.exe
```

采集后不打开 GUI，直接在终端看报告：

```powershell
# 总览
vtune -report summary -r .\result-hotspots

# 热点函数列表
vtune -report hotspots -r .\result-hotspots

# 导出 CSV，方便 Excel 分析
vtune -report hotspots -r .\result-hotspots -format csv -report-output .\hotspots.csv
```

一些很实用的结果管理命令：

```powershell
# 查看某个结果包含哪些可用报告
vtune -help report

# 将不完整的结果进行最终处理
vtune -finalize -r .\result-hotspots

# 导入已有结果
vtune -import .\some-result.vtune -r .\imported-result
```

建议你的实际使用顺序：

```powershell
# 1. 先定位 CPU 耗时位置
vtune -collect hotspots -r .\vtune-hotspots -- .\app.exe

# 2. 终端快速看摘要
vtune -report summary -r .\vtune-hotspots

# 3. 图形界面深入看调用栈和源码
vtune-gui .\vtune-hotspots
```

Windows 下，`hotspots` 是最稳妥的第一个命令。确认程序耗时集中在哪里后，再根据情况运行 `threading`、`memory-access` 或 GPU 分析。
