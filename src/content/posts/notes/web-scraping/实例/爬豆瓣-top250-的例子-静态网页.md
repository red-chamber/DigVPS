```python
import requests  
from bs4 import BeautifulSoup  
import csv  
import time  
  
# ─── 配置 ───────────────────────────
HEADERS = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'}  
CSV_FILE = 'douban_top250.csv'  
  
# ─── 抓取一页 ───────────────────────
def scrape_page(start):  
    """抓取第 start 条开始的 25 部电影，start 每次自增 25，实现自动翻页"""  
    url = f'https://movie.douban.com/top250?start={start}'  
    resp = requests.get(url, headers=HEADERS, timeout=10)  
    soup = BeautifulSoup(resp.text, 'html.parser')  
  
    movies = []  
    for item in soup.select('.grid_view .item'):  
        title = item.select_one('.title').text                 # 名称  
        rating = item.select_one('.rating_num').text            # 评分  
        quote_tag = item.select_one('.quote span')  
        quote = quote_tag.text.strip() if quote_tag else ''    # 简介（可能为空）  
  
        movies.append([title, rating, quote])  
    return movies  
  
# ─── 主函数 ─────────────────────────
def main():  
    all_movies = []  
  
    for page in range(10):  # 10 页，每页 25 部  
        start = page * 25  
        print(f'正在抓取第 {page+1}/10 页...')  
        movies = scrape_page(start)  
        all_movies.extend(movies)  
        time.sleep(1)  # 礼貌停顿  
  
    # 写入 CSV    
    with open(CSV_FILE, 'w', newline='', encoding='utf-8-sig') as f:  
        writer = csv.writer(f)  
        writer.writerow(['名称', '评分', '简介'])  # 表头  
        writer.writerows(all_movies)  
  
    print(f'完成！共 {len(all_movies)} 部电影，已保存到 {CSV_FILE}')  
  
if __name__ == '__main__':  
    main()
```

注：
1. `soup = BeautifulSoup(resp.text, 'html.parser')` 的 `html.parser` 是一种 html 解析器，一般 `lxml` 就够用了

| 解析器             | 安装                     | 速度  | 容错能力       |
| --------------- | ---------------------- | --- | ---------- |
| `'html.parser'` | **Python 自带，无需安装**     | 中等  | 一般         |
| `'lxml'`        | `pip install lxml`     | 快   | 强          |
| `'html5lib'`    | `pip install html5lib` | 慢   | 最强（同浏览器行为） |
2. `soup.select('.grid_view .item')` 的 `.grid_view` 是查找 `class=grid_view` 的元素，再加一个 `.item` 就是查找 `class=grid_view` 里面 `class=item` 的元素（空格就是里面的意思）。这些是 CSS 的标准写法

| `.类名`  | → class="类名" |
| ------ | ------------ |
| `#id名` | id="id名"     |
| `标签名`  | <标签名>        |
