## 一、实现 get 请求

```python
import requests
url = 'https://www.httpbin.org/get' # 要请求信息的网址（这里的这个网址是实验网址，正常来说权威后不一定要加 /get，只看你要请求什么 API）
response = requests.get(url) # get 方法，见下
print(response.status_code) # 状态码
print(response.text) # response 的详细信息
```

### requests.get()
1. 基本签名

```python
requests.get(url, params=None, **kwargs) 
```
- **`url`** — 请求地址
- **`params`** — URL 查询参数（自动编码拼接到 URL 问号后面）
- **`**kwargs`** — 其他可选参数（headers, **timeout**, cookies, proxies, verify, allow_redirects 等）

2. 常用参数

| 参数        | 作用                 |
| --------- | ------------------ |
| `params`  | 字典，自动拼接为 URL 查询字符串 |
| `headers` | 字典，自定义请求头          |
| `timeout` | 超时时间（秒）            |
| `cookies` | 字典，发送 Cookie       |
3. 进阶一点的例子

```python
import requests  
import json # 为了让 resp 的输出内容格式化
  
url = 'https://postman-echo.com/get' # 之前那个太繁忙503了
params = {'name': '张三', 'age': 18}  
cookies = {'session_id': 'abc123'}  

resp = requests.get(  
    url,  
    params=params,  # 查询参数，即过滤条件
    cookies=cookies,  # 用于识别用户
    timeout=5  # 超时时间
)  
  
if resp.status_code == 200:  
    print("请求成功，状态码：",resp.status_code,'\n',json.dumps(resp.json(), indent=2, ensure_ascii=False))  
else:  
    print("请求失败，状态码：",resp.status_code)
```

输出：

```text
请求成功，状态码： 200 
 {
  "args": {
    "name": "张三",
    "age": "18"
  },
  "headers": {
    "host": "postman-echo.com",
    "x-forwarded-proto": "https",
    "accept-encoding": "gzip, br",
    "user-agent": "python-requests/2.32.5",
    "accept": "*/*",
    "cookie": "session_id=abc123"
  },
  "url": "https://postman-echo.com/get?name=%E5%BC%A0%E4%B8%89&age=18"
}
```

> 注：headers 就是请求头，告诉服务器"我是谁、我能接受什么格式、连接怎么保持"等**元信息**

## 二、用 Cookie 维持登录状态

```python
url = 'https://login2.scrape.center/'
```

## 三、fake_useragent 生成 UserAgent

UserAgent 用户代理，相当于浏览器的身份证号，在请求头中。在利用爬虫爬取网站数据时，频繁更换它可以避免触发相应的反爬机制。

```python
import requests  
from fake_useragent import UserAgent  
  
url = 'https://postman-echo.com/get'  
ua = UserAgent()  
headers = {  
  'user-Agent':ua.random,  
}  
response = requests.get(url,headers=headers)  
print(response.status_code)  
print(ua.random)
```

```text
200
Mozilla/5.0 (iPhone; CPU iPhone OS 18_3_1 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/18.3 Mobile/15E148 Safari/604.1
```

> 有时 iPhone，有时 Windows，有时 Linux，etc.

## 五、tqdm 生成进度条

```python
from tqdm import tqdm  
import time  
  
dic = ['a', 'b', 'c', 'd', 'e']  
pbar = tqdm(dic)  
for i in pbar:  
    pbar.set_description('Processing '+i)  
    time.sleep(1.1) # 每隔 1.1 秒进度条涨一点
```

```text
Processing e: 100%|██████████| 5/5 [00:05<00:00,  1.10s/it]
```

> dic 有 5 个元素，故涨 5 下到满格

## 六、MongoDb数据库

```python
# 导入包
import  pymongo  
  
# 创建一个 MongoDB 客户端，连接到本地的 27017 端口。如果服务没启动，这行会报错 Connection refused
client = pymongo.MongoClient(host='localhost',port=27017)  

# 列出当前 MongoDB 实例中所有数据库名字，返回一个列表，但只是查询，没有打印
client.list_database_names()  

# 创建一个叫 test 的数据库，等价于 client['test']
# MongoDB 是懒创建，只有在真正插入数据时才实际创建。
db = client.test  

# 列出 test 数据库下所有集合的名字，同样只是查询
db.list_collection_names()  

# 选中 test 数据库下的 comments 集合，等价于 db['comments']
collections = db.comments  

# 打印这个集合对象本身，不是打印集合里的数据
print(collections)  
  
data={"name":"Man","University":"HUST"}  

# 向 comments 集合中插入一条文档，MongoDB 会自动给它加一个 _id 字段
# 这一步之后数据库才真正创建了 test 数据库和 comments 集合
collections.insert_one(data)  

# 查询 comments 集合中 name 字段等于 "Man" 的第一条文档，返回一个字典。如果没找到就返回 None
results = collections.find_one({"name": "Man"})  
print(results)
```
